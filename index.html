Moon Dust Tycoon Backup

This is a personal tool used by the developer of Moon Dust Tycoon, a Roblox game in development, to back up project files to the developer's own Google Drive.

It is not a public service: it does not offer accounts, does not accept sign-ups and is used only by its owner. Backups are made with the open-source program rclone, authorized through Google sign-in.

Read the Privacy Policy.
