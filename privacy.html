Privacy Policy

Last updated: November 1, 2026.

"Moon Dust Tycoon Backup" (the "App") is a personal backup tool used only by its owner, the developer of the Roblox game Moon Dust Tycoon. This policy explains how the App handles Google user data.

What the App accesses

When its owner signs in with Google, the App gets access to that account's Google Drive. It uses this access only to upload, list, download and delete the owner's own project files and backups in a project folder.

What the App does not do

  • It does not collect, store or process data on any server other than Google Drive itself.
  • It does not share, sell or transfer Google user data to anyone.
  • It does not use Google user data for advertising, analytics or training of any models.
  • It is not offered to other users.

Where credentials are kept

The sign-in token issued by Google is stored only in a configuration file on the owner's own computer and is never published or sent anywhere except to Google.

Google API Services User Data Policy

The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time on the Google Account permissions page.
